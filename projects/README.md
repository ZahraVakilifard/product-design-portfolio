# Product Design Portfolio — Three Interactive Concepts

Three self-initiated concept prototypes, built with plain HTML, CSS and JavaScript. No build tooling or dependencies are required.

## Projects

- **SIGNAL** — cohort explorer for merchant retention investigation; selectable cohorts, periods, journey stages and testable hypotheses.
- **LOOP** — mobile reward redemption journey with selection, checkout calculation and confirmation.
- **LAUNCHPAD** — merchant loyalty setup with editable rules, live preview, validation and local-only activation.

## Run

Open `index.html` in a browser, or serve the folder locally with `python -m http.server 8000` and visit `http://localhost:8000`.

## Publish

Upload the contents of this folder to a GitHub repository and enable GitHub Pages with `main` branch / root. Link to `signal/`, `loop/`, and `launchpad/` from an existing portfolio website.

## Important disclosure

All three projects are **independent concepts**. Figures, customers, and business scenarios are illustrative. No user research, real-user usability testing, production deployment, or measured business outcomes are claimed. These are prototype foundations, not finished, validated end-to-end case studies.

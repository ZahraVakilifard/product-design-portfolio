# Product Design Portfolio — SIGNAL / LOOP / LAUNCHPAD

A self-initiated portfolio concept containing a landing page and three interactive product explorations.

## Open locally
Open the root `index.html` in a browser. Click **Explore full project** on any of the three featured projects.

## Structure
- `index.html`, `styles.css`, `script.js`: main portfolio
- `projects/signal/`: customer journey exploration
- `projects/loop/`: reward redemption flow
- `projects/launchpad/`: merchant program builder
- `projects/shared.css`: shared styles for the three projects
- `projects/index.html`: optional standalone project directory

## Publish to GitHub Pages
Upload the *contents* of this folder to the root of a GitHub repository.
In GitHub Settings → Pages, select **Deploy from a branch**, branch `main`, folder `/(root)`.
The relative links work on project pages and on the homepage.

## Important
All projects are self-initiated illustrative prototypes. Data, scenarios, and business values are fictional.
No real user research, validated outcomes, or production deployment is claimed.
Replace the placeholder contact address in the homepage before publishing.

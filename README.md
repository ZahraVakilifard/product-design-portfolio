# PRODUCT DESIGN / Four interactive concept case studies

An original responsive portfolio website featuring four self-initiated product design concepts, each with a working interactive prototype and a structured case study.

## Quick start
Open `index.html` in a browser. No build process, framework, or package installation is required.

## Site map
- `/index.html` — homepage, scroll-reactive perspective tunnel, work, approach, playground, contact
- `/projects/signal/index.html` — retention intelligence, cohort selection, journey exploration, hypothesis framing
- `/projects/loop/index.html` — loyalty points, reward selection, checkout review, demo confirmation
- `/projects/launchpad/index.html` — program goal, rule editor, live preview, validation, demo activation
- `/projects/pulse/index.html` — campaign variants, audience, tone, theme, offer, square/story layouts

## Each case study includes
- User/problem framing and intended audience
- Design goal and constraints
- Three design principles
- Five-step task flow
- Three key design decisions with explicit trade-offs
- Visual design tokens and interaction principles
- Edge cases and states
- Proposed usability-testing questions and success measures
- A link back to its interactive prototype

## GitHub Pages
Push the contents of this folder into a repository, then configure Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Before you use this as a personal job application
1. Replace `hello@example.com` in the homepage and add your actual name, professional bio, social links, and contact details.
2. Review and revise the product decisions in your own words so you can explain them independently.
3. Create actual Figma design files and capture authentic sketches, alternatives, and iterations.
4. Conduct real usability tests before claiming research findings, validation, or measurable outcomes.
5. Replace the fictional numbers, personas, and example scenarios with responsibly sourced or clearly labeled synthetic material.

## Integrity
All four projects are independent **concepts**, not client commissions or production systems. Metrics and transactions are fictional examples. The case studies describe design hypotheses, proposed decisions, and testing plans. No research participants, measured business results, or employer affiliations are invented.

## Tech
HTML, CSS, vanilla JavaScript, Canvas 2D. Uses Google Fonts with fallback fonts. Supports mobile layouts, keyboard focus, and reduced-motion settings.
